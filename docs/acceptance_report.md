## 实际验证

本地 22 项自动化测试通过，包含合成 ETL 新目录重建、真实既有分析库 OOF 指标对照、SQL 与浏览器筛选一致性、分母、边界及白名单。静态站构建包括 9 项资产。浏览器检查覆盖七页桌面和手机、筛选、空状态、时点、模拟标记下载及本地授权版 Table 1、回归、实验曲线和风险审查。静态站测试期间无 API 请求。

## 研究限制

单中心 Development 内部验证，旧 Test 已暴露。仅死亡日期者的风险集边界和随访覆盖限制解释。年龄与记录性别的相互调整适合探索，仍有残余混杂。年龄边界分析和亚组描述没有确认性效力。原论文完整变量集、SAPS III 和外部验证仍有缺口。

## 工程与下一步

本地科研入口依赖获授权的既有完整项目和阶段二产物登记。发布站点采用静态模拟数据。将全套历史训练迁入这个公开平台仓库会改变工程范围，现有训练链已单独归档。本地研究报告已补齐纳排计数、风险集与精确 90 天结局边界敏感性。后续独立验证仍需另立方案。

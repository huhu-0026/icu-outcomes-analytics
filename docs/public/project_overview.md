# 项目概览

这个个人项目记录了我学习临床研究和医学 AI 的实践。我从 ICU 入科后的时点预测入手，练习定义队列和结局、约束预测时能用的信息、按患者验证模型，并把分析做成可检查的结果。

预测研究的结局是从入科日计的 90 天内有记录的死亡。我先比较只看时点快照的逻辑回归与使用历史序列的 LSTM，再检查同一 LSTM 校准前后的概率误差，并用分组特征贡献理解模型输出。队列和基线分析说明各项结果对应哪些患者和 ICU 停留。

本仓库可以跑通独立模拟演示，也可在授权环境中将冻结产物导入分析库，复算折外评价并查看统计结果。完整历史队列构建、特征工程和训练由本地研究项目保存。读者可从在线演示查看交互，从研究文档核查口径，再从源码追溯本仓库实现。

# 项目概览

基于 MIMIC-IV 的临床数据研究与智能预测分析平台是一项个人研究与工程实践。核心问题是 ICU 入科后，如何利用当时能获得的病历信息估计从入科日计的 90 天死亡风险。

三个能力层形成一条链。临床研究确定问题、风险集和分析计划。医学数据工程将病历表转成可追溯、可检查的分析对象。医学 AI 使用患者级验证评价概率和排序，并解释模型所用临床概念。

看板按照研究总览、队列、基线、临床统计、动态预测、解释和质量组织。公开演示支持独立模拟数据操作。研究结果在经授权的本地完整项目及新增只读审查产物中查看。

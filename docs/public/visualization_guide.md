# 可视化与可追溯报告

| 页面 | 回答的问题 | 数据与口径 |
|---|---|---|
| 研究总览 | 临床问题如何接到工程与验证？ | 工作流、PICOTS、技术架构。无结果数字的流程块为设计说明 |
| 临床队列构建 | 继续到每个时点的停留有多少？ | 同时显示患者、住院、停留。时点覆盖按停留与独立患者计。真实审查另显示差额 |
| 患者基线特征 | 队列的患者结构如何？ | 年龄和性别画像可筛选。科室按停留。完整队列 Table 1 一人一索引停留 |
| 临床统计分析 | 结局组有哪些差异？ | Table 1 的 SMD、描述性亚组、授权本地调整 OR 与敏感性。下方诊断处方仅回顾性 |
| 动态预测模型 | 风险排序、概率质量及阈值表现怎样？ | 每时点各实验的 ROC、PR、AUROC/ AP / Brier / MCC、校准和混淆矩阵 |
| 模型解释性 | 哪些历史组与输出关联？ | 真实 v06 与模拟示意分开，贡献用百分点 |
| 数据质量与复现 | 分母与缺失怎样复核？ | 数据约束、时点可用数、源文件与项目入口 |

人群筛选作用于队列和描述性画像及临床记录汇总。Table 1、调整模型、风险审查和模型评价依完整已定义人群报告。切换模型时点不会改变实验版本。导出的 JSON 明确带数据分类，跨小人群筛选后的结果不应转为公开资料。

| 本地独立图 | 可用场景 |
|---|---|
| `risk_set_sensitivity` | 对照冻结风险集与只有 LOS 门槛的风险集 |
| `descriptive_comparisons` | 结局组年龄 IQR、按记录性别描述结局 |
| `adjusted_associations` | 完整病例和年龄 <90 的 OR / CI |
| `population_and_missingness` | 首次科室与记录性别计数，以及 1h 主要缺失变量 |
| `v04_calibration` | 同一组折外预测的四时点分箱校准 |
| `v03_baseline_performance`、`v04_nested_performance` | 匹配各自主时点的曲线、混淆计数和四时点趋势 |

本地 PNG / SVG 由相同研究汇总生成，授权本地访问。照片和图表中的 SYNTHETIC 字样用于确认公开演示数据来源。

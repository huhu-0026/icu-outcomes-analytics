# 指标字典与分析边界

| 指标 | 粒度 / 分母 | 筛选范围 |
|---|---|---|
| 独立患者 | 当前选中 ICU 停留中的 distinct patient_id | 性别、首次符合条件年龄、首次 ICU 科室 |
| 符合条件住院 | 当前选中 ICU 停留中的 distinct admission_id | 同上，仅队列所涉住院 |
| ICU 停留 | fact_icu_stay 的行数 | 同上 |
| 平均年龄 | 每位患者首次符合条件 ICU 时已知年龄 | 同上，缺失不当高龄 |
| 平均 ICU 时长 | 完整停留天数的算术平均 | 同上，非预测输入 |
| 90 天结局率 | ICU 停留结局之均值 | 自入 ICU 起 90 天，非滚动窗口；重复住院可重复计患者结局 |
| 诊断频次 | 每住院/编码/版本一条，按名称汇总 | 所选停留涉及的住院，回顾性 |
| 处方记录 | 源 prescriptions 行数；按住院/标准化名称聚合 | 同上，非实际给药与剂量 |
| 预测覆盖 | 在 h 时点仍有合法预测的停留数 | 人群筛选 + h |
| AUROC / AP / Brier | 冻结实验的全队列有效折外预测 | 仅 h；v03 / v04 分开 |
| 缺失率 | 1 - known / risk_stays | 冻结全队列、仅 h |
| 特征贡献 | 13 分组历史贡献的平均绝对值（百分点） | 真实研究为抽样解释，模拟版为示意值 |

星形关系：患者 1→N 住院 1→N ICU 1→N 时点预测；住院 1→N 诊断、住院 1→N 处方。显示层不能把每个切片的 distinct patient 数简单相加当总体。

模型区分两套实验：v03 的基准 Logistic/LSTM，v04 独立患者角色划分的校准前后 LSTM。比较校准收益时只比较 v04 内的 nested_raw 与 isotonic；v03 有不同训练角色，不是 v04 校准前的同一网络。

真实临床输入沿用已核验研究特征，未因看板增加出院诊断或完整住院处方。看板是结果展示层，不是实时临床预测系统，也未做外部验证。

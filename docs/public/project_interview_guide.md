# 项目介绍与面试讲解

## 临床研究岗位 · 60 秒

我用 MIMIC-IV 做了一项 ICU 90 天死亡风险的回顾性研究实践。我先用 PICOTS 明确人群、索引时点和结局，再复核患者级分区和每个时点仍可评价的风险集。我按患者首个合格 ICU 做 Table 1，比较结局组并探索年龄与记录性别的调整关联。在预测部分，我解释为什么排序、校准和临床阈值需要不同证据。项目记录了日期级结局、随访和外部验证的局限。

## 医疗数据分析岗位 · 60 秒

我把患者、住院和 ICU 停留作为不同粒度建模，用分块 ETL、SQL 半连接、外键和预测索引核对处理整条数据链。看板给出分母、动态风险集、Table 1、模型评价和数据质量，并区分需要随筛选更新的汇总与完整队列的固定实验指标。我为公开演示建立了独立模拟库和资产白名单。

## 五分钟讲解

1. 研究总览讲 PICOTS 和预测目标。
2. 在队列页解释患者和停留，切换时点说明分母随风险集变化。
3. 在基线与统计页展示一个分母、一个 SMD 和一个调整模型局限。
4. 在模型页对照 ROC、PR、校准与固定阈值，解释为什么 v03 和 v04 分开比较。
5. 从质量页指出一个字段的来源及一个版本核验步骤。

## 常见追问

- **如何防止泄漏？** 按患者分折，折内预处理，同时限制测量和报告时间。诊断及处方回顾性分析与预测输入分开。
- **调整 OR 可以当因果效应吗？** 只纳入年龄与记录性别，其他病情和治疗差异可能影响关联。这是探索性描述。
- **为什么历史 Test 不能作为新确认？** 既往已使用。重新命名无法恢复独立性。
- **为何用模拟网站？** 线上可验证工程交互。受限数据及研究产物按 PhysioNet 规则经授权使用。
- **如何复现一个数？** 选实验、患者范围与时点，从保存 OOF 和 mask 重算并核对冻结表。

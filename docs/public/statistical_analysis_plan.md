# 统计分析计划

适用模块为本地 Development 只读研究审查 `M4-PORTFOLIO-DESCRIPTIVE-20261119`。该文档记录已实施的探索性方法及后续范围。既有实验分别采用其冻结方案。

| 分析 | 单位与做法 | 解释 |
|---|---|---|
| 队列构建 | 每次 ICU 停留，患者和住院分别去重 | 时点覆盖报告风险集分母 |
| Table 1 | 每人按 intime、stay_id 排序取首个合格 ICU | 连续量报告中位数和 IQR、有效及缺失分母。分类量报告 n/N 与百分比 |
| 组间比较 | 按 90 天标签分层，事件组减非事件组 | 连续量用两组样本方差平均值开根后标准化均值差。分类量逐水平用 Bernoulli 方差标准化。零方差及样本不足显示缺失 |
| 探索性回归 | 索引停留中年龄与记录性别均完整。二项 GLM、logit 链接、HC1 95% CI | 报告年龄每 10 岁与 M 相对 F 的相互调整 OR。混杂控制仅限模型所含协变量，残余混杂仍存在 |
| 描述性亚组 | 按记录性别汇总索引停留事件和组内分母 | 不进行交互检验或亚组预测性能搜索 |
| 敏感性 | 同规格回归限制年龄 <90。比较 LOS≥时点与冻结风险集 | 检查年龄编码边界及分母定义。假设与结果仅针对各自人群 |
| 预测评价 | 停留×时点，按已有 Development OOF 与实验ID | AUROC、AP、Brier、MCC、混淆矩阵。分类阈值固定 0.50。原报告患者簇区间条件于已拟合模型 |

Table 1 的 1 小时临床量按索引停留提取，明确有无有效测量。入 ICU 前住院天数与年龄属于时点前信息。诊断和处方回顾性描述以住院为分母范围，可能含预测时点以后信息。

当前目标为描述与探索。开展因果问题、更多协变量控制或交互检验前需明确目标效应、入组时间和可识别假设。完成独立验证需要未被同一开发流程接触的数据。

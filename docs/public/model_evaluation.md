# 模型评价与解释

| 问题 | 指标、曲线与分母 |
|---|---|
| 能否排序 | AUROC 与 ROC，AP 与 PR。AP 采用 precision 随 recall 的阶梯积分，PR 基线使用该时点阳性率 |
| 概率误差多大 | Brier 为平均平方误差。校准图比较箱内平均预测与观察比例 |
| 固定阈值怎样表现 | p≥0.50 为阳性。提供 TN、FP、FN、TP 和 MCC。分母退化显示空值 |
| 随时点怎样变化 | 每个点使用本时点风险集。不能解释为同一群人的个体概率改善 |
| 哪些历史特征组对输出贡献较大 | 分组特征解释按概率百分点汇总 13 组平均绝对贡献，使用折外样本和训练侧参照 |

模型比较对照逻辑回归与 LSTM。概率校准对照同一网络的原概率和经过 Isotonic 映射的概率。所有模型曲线、计数和指标绑定具体分析和预测时点。图上的下采样只用于显示，统计量由原曲线计算。0.50 是描述阈值，临床阈值选择尚未验证。

Isotonic 能改变并列排序。应同时查看首小时概率误差与其他时点结果。一处指标改善不能推导所有时点均变化相同。分组 Shapley 贡献的解读受变量相关性和参照选择影响。无因果或临床应用结论。

公开版曲线由独立模拟评分计算，贡献为标明的展示示意。授权本地读冻结 Development OOF，并核对 AUROC、AP、Brier、混淆计数。没有新增外部验证。

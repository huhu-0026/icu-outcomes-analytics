# 模型评价与解释

| 问题 | 指标、曲线与分母 |
|---|---|
| 能否排序 | AUROC 与 ROC，AP 与 PR。AP 采用 precision 随 recall 的阶梯积分，PR 基线使用该时点阳性率 |
| 概率误差多大 | Brier 为平均平方误差。校准图比较箱内平均预测与观察比例 |
| 固定阈值怎样表现 | p≥0.50 为阳性。提供 TN、FP、FN、TP 和 MCC。分母退化显示空值 |
| 随时点怎样变化 | 每个点使用本时点风险集。不能解释为同一群人的个体概率改善 |
| 哪些历史组影响输出 | v06 按概率百分点汇总绝对分组历史贡献，13 组、折外抽样、仅训练侧参照 |

v03 比较 Logistic 与 LSTM，v04 比较同一嵌套网络的原概率与 Isotonic。所有模型曲线、计数和指标绑定实验及预测时点。图上的下采样只用于显示，统计量由原曲线计算。冻结 0.50 是描述阈值，临床阈值选择尚未验证。

Isotonic 能改变并列排序。应同时查看首小时概率误差与其他时点结果。一处指标改善不能推导所有时点均变化相同。v06 是分组历史 Shapley 解释，相关变量与参照选择限制解释。无因果或临床应用结论。

公开版曲线由独立模拟评分计算，贡献为标明的展示示意。授权本地读冻结 Development OOF，并核对 AUROC、AP、Brier、混淆计数。没有新增外部验证。

| 能力 | 审查结论 | 证据与改进点 |

平台链路为授权源表及冻结研究结果 → Python ETL → SQLite → 参数化 SQL → 本地 Web / 分表 CSV。公开演示由独立模拟库编译成静态资产，浏览器筛选。既有测试涵盖外键、重复计数、SQL 与浏览器一致性、本地端点和 Pages，缺少统计定义、独立 ETL 夹具、科研结果键、图表与发布资产的专项检查。

## 研究上的优先问题

- Development 内部五折证据可保留。v04 首小时由上游早期校准问题推动，属于后续内部研究。v03 的 24 小时模型对比与 v04 的同网络校准对比应各自报告。
- 24/48/72 小时分母沿用出 ICU 和死亡筛选。DOD 只有日期时会排除死亡当天的部分时点。90 天结局使用入科日到第 90 日的闭区间，DOD 缺失不能证明随访完整。
- 描述性结局分组与回归应选每人首个合格 ICU 停留，避免重复停留加权和伪独立。队列总体展示可保留停留粒度并标注分母。
- 解释产物为 13 组历史 Shapley 方法。模型解释和临床效应应分别陈述。
